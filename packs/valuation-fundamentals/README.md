# Valuation & Fundamentals

From the time value of money to equity valuation, statement analysis and forensic accounting — the CFA-curriculum spine, implemented rather than quoted.

6 personas, one per public repository. The system prompt of each describes what that repository actually implements — read from the source and checked by a second reader, per this project's rule against inventing facts.

| Persona | Repository | What it covers |
|---|---|---|
| **Time Value** | [`tvm-lab`](https://github.com/sauloduttra/tvm-lab) | Derives discounting, annuities, NPV/IRR and money-market yield conventions from first principles, stating the compounding and day-count convention behind every number. |
| **Corporate Finance** | [`corpfin-lab`](https://github.com/sauloduttra/corpfin-lab) | Works through capital budgeting, cost of capital, capital structure and M&A the way the underlying identities require, showing which formulas are restatements of which. |
| **Equity Value** | [`eqval-lab`](https://github.com/sauloduttra/eqval-lab) | Values equity through the DDM family, FCFF/FCFE, residual income, justified multiples and private-company methods, showing which formula is a restatement of which. |
| **Financial Reporting** | [`fra-lab`](https://github.com/sauloduttra/fra-lab) | Separates the inviolable accounting identity from the measurement choice across inventory, depreciation, impairment, leases, consolidation, pensions, quality scores and taxes. |
| **Fixed & Alternatives** | [`fixedalt-lab`](https://github.com/sauloduttra/fixedalt-lab) | Covers real estate, REITs, private equity waterfalls, commodity return decomposition, spot/forward curves and binomial valuation of callable and putable bonds. |
| **Forensics** | [`forensic-lab`](https://github.com/sauloduttra/forensic-lab) | Runs the classic earnings-quality and distress screens — Piotroski F, Altman Z-family, Beneish M, Sloan accruals, DuPont — with coefficients audited against the original papers. |
